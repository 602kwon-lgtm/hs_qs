02

하락은 착시다 — 그러나 상승도 아니다

  • QS 2026년 평가대상, 987개교 → 1,534개교로 55% 확대
  • 순위 숫자만 보면 2년간 150계단 하락
  • 그러나 한성대보다 낮은 대학은 162곳 → 671곳으로 증가
  • 백분위 환산: 하위 15%권 → 중위권 바로 아래(상위 57%)로 상승
반증 검증 — 고정 코호트
  • 모집단 확대 효과를 제거하기 위해 3개년 모두 평가된 652개교만으로 재계산
  • 고정 집단 백분위: 86.5%(2024) → 94.6%(2025) → 86.7%(2026)
  • 즉 2026년 개선은 2025년 급락의 복귀일 뿐 — 2024년 대비 순증은 아님
  • “백분위 27%p 개선”은 대외 커뮤니케이션용 표현으로는 가능하나, 내부 목표 설정 근거로는 부적절
03

개선분의 40%는 다시 오지 않는다

  • 복원 총점, 9.72점(2025) → 19.21점(2026)으로 +9.49점 상승
  • 이 중 +3.82점(40.3%)은 박사학위 교원 비율(Staff with PhD) 단일 지표에서 발생
  • SWP는 2024·2025년 데이터 미제출로 0점 처리 → 2026년 76.4점으로 최초 집계된 1회성 효과
  • 비교 기준이 문제 — QS는 신규 대학 편입 시마다 점수를 재정규화, 실적 변화 없이도 전체 점수가 동반 상승
  • 700–950위 구간 임계 총점은 2025년 대비 평균 +10.96점 상승
  • 반면 한성대 상승분은 +9.49점으로 코호트 평균에 미달
핵심 진단
  • 한성대 상승(+9.49) vs 코호트 기준선 상승(+10.96) → 실질 상대 이동 −1.47점
  • 1회성 박사학위 교원 효과(+3.82) 제외 시 실질 상대 이동은 −5.29점까지 확대
  • 2027년에는 1회성 방패가 소멸 — 현재 속도 유지 시 901–950위 이하로 하락 전망

  • Scopus 소속기관 프로파일 정비 — 소속 표기 불일치(Hansung Univ. / 한성대 / Hansung University Seoul)로 누락된 논문 병합

2순위

국제공동연구망(IRN) — 단일 최대 병목

6–18개월

IRN 3.1점 = 국내 100개교 중 97위(하위 3%) — 논문 절대량이 아닌 국제 공저 파트너의 국가·기관 다양성을 측정, 연구비 규모보다 협력 설계가 핵심 변수. 경기대(56.4)·조선대(42.9)·계명대(42.2)가 낮은 평판에도 앞서는 이유가 여기 있음.

  • 교원 1인당 연 1편 국제 공저 목표 — 공저 국가 수를 KPI에 명시(편수가 아니라 국가 다양성)
  • 기존 자매결연 대학과의 공동연구 시드머니 신설 — 협정을 논문으로 전환하는 최단 경로
